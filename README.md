# HireMEgent AI 🚀
### Your AI-Powered Career Command Centre

**Designed & Developed by 1SH6YAAN**

HireMEgent AI is an intelligent career assistant that helps job seekers analyze their resumes, discover practical projects, build career roadmaps, match job opportunities, practice interviews, and manage applications — all through one futuristic workspace.

## ✨ Features

| Module | Description |
|---|---|
| Resume Intelligence | AI-powered resume analysis, strengths, weaknesses and skill extraction |
| AI Project Lab | Personalized project ideas based on career goals and experience |
| Career Roadmap | Structured learning plans and career milestones |
| Job Matcher | Resume-to-job-description matching and recommendations |
| AI Interview Studio | Interview question generation and answer evaluation |
| Application Tracker | Track job applications, statuses and career statistics |

## 🧠 AI Architecture

- Local AI inference through Ollama
- Llama 3.2 (3B) language model
- FastAPI backend
- React frontend
- SQLite application database

No Gemini API key or paid AI API is required for the local AI workflow.
